# Reverse 1320

Android-first, Windows-second modern drag-racing rebuild inspired by the systems and feel of classic Nitto 1320 titles.

## Project rules

- Upgrade, never downgrade: physics, tuning depth, UX, multiplayer, sound and visuals must exceed the original experience.
- No generic AI-looking production art. Vehicle and environment assets must use authored, production-quality game-art workflows.
- Android is the reference platform. Windows ships from the same Unreal gameplay codebase with higher visual tiers.
- Recovered legacy material is kept as forensic/reference data and is not mixed blindly into production assets.
- Vehicle reference sheets are used to validate proportion, stance and customization direction; final cars must be proper 3D game assets.

## Current milestone

Phase 4 — Android vehicle runtime, drag physics calibration, production vehicle pipeline and first device-build gate.
